# Customer Shopping Behavior Analysis

## Overview
An end-to-end data analytics project that analyzes customer shopping behavior to identify purchasing trends, customer segments, and product preferences. The goal is to generate actionable insights that support better marketing strategies, customer engagement, and business decisions.

## Dataset
- Records: 3,900 purchases
- Features: 18 columns
- Key Data: Customer demographics, purchase details, discounts, subscriptions, and review ratings.

## Tools & Technologies
- Python: Pandas, NumPy
- PostgreSQL: SQL queries and business analysis
- Power BI: Interactive dashboard and data visualization
- Jupyter Notebook: Data analysis and exploration

## Project Workflow
1. Data Loading & EDA: Loaded the dataset into Python and explored its structure and statistics.
2. Data Cleaning: Handled missing values, standardized column names, and performed feature engineering.
3. SQL Analysis: Loaded cleaned data into PostgreSQL and analyzed revenue, customer segments, subscriptions, discounts, and product ratings.
4. Dashboard Development: Built an interactive Power BI dashboard to visualize key trends and insights.
5. Reporting: Prepared a project report with business insights and recommendations.

## Dashboard
The Power BI dashboard presents key insights into customer purchasing patterns, revenue trends, product preferences, and subscription behavior.

## Key Results
- Analyzed revenue across customer demographics and age groups.
- Identified customer segments based on purchase history.
- Evaluated discount usage, product ratings, and shipping preferences.
- Developed recommendations for customer loyalty, subscription growth, and targeted marketing.

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/achal-gadage/customer_behavior_analysis.git
   ```
2. Navigate to the project folder:
   ```bash
   cd customer_behavior_analysis
   ```
3. Install the required Python libraries:
   ```bash
   pip install pandas numpy sqlalchemy psycopg2-binary jupyter
   ```
4. Open Jupyter Notebook and run the data cleaning and EDA steps.
5. Configure PostgreSQL credentials and create the `customer_behavior` database.
6. Execute the SQL queries in PostgreSQL.
7. Open the Power BI `.pbix` file to explore the interactive dashboard.
